# Design Handoff

Use this skill when a project needs wireframes and design guidance that engineers can directly implement.

## Trigger
- The user asks for a new page, flow, or product direction
- The UI is still ambiguous and implementation would otherwise guess

## Do Not Trigger
- Tiny copy changes
- Pure backend work with no user-facing flow

## Inputs
- Product brief
- Target users
- Supported devices
- Brand or style constraints

## Outputs
- `_workspace/01_design_wireframes.md`
- `_workspace/01_design_handoff.md`

## Procedure
1. List primary user goals and critical pages or screens.
2. Write low-fidelity wireframes in text form with sections, components, and hierarchy.
3. Cover default, empty, loading, error, and success states.
4. Define responsive expectations for mobile and desktop.
5. Translate the wireframes into a concise build handoff with component names and interaction notes.
